# Три цикла — план подготовки

Приложение для iPhone: тренировки, питание, восстановление и справка на 12 месяцев.
Работает без интернета, данные хранятся на телефоне.

## Установка на iPhone

1. Открой ссылку на приложение **в Safari** (не в Telegram и не в Chrome).
2. Нажми «Поделиться» (квадрат со стрелкой вверх) внизу экрана.
3. Выбери «На экран Домой» → «Добавить».

На экране появится иконка «Три цикла». Приложение открывается на весь экран, без адресной строки.

## Данные

- Галочки, дневник питания и выбранная неделя хранятся только на телефоне.
- Сайт в Safari и приложение с экрана «Домой» хранят данные раздельно, поэтому пользуйся иконкой.
- Резервная копия: «Справка» → «Данные и резервная копия» → «Сохранить копию» (в Файлы или Telegram).

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | всё приложение: план, логика, схемы движений |
| `manifest.webmanifest` | название и иконка для экрана «Домой» |
| `sw.js` | офлайн-режим (при изменении `index.html` подними `VERSION`) |
| `icons/` | иконки |
