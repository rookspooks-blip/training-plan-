# Три цикла — план подготовки

Приложение для iPhone: тренировки, питание, прогресс, восстановление и справка на год.
Работает без интернета, данные хранятся на телефоне.

## Установка на iPhone

1. Открой ссылку на приложение **в Safari** (не в Telegram и не в Chrome).
2. Нажми «Поделиться» (квадрат со стрелкой вверх) внизу экрана.
3. Выбери «На экран Домой» → «Добавить».

На экране появится иконка «Три цикла». Приложение открывается на весь экран, без адресной строки.

## Что внутри

- **Сегодня** — тренировка выбранного дня (полоса дней сверху), журнал подходов с подсказкой веса,
  таймер отдыха, светофор колена в прыжковые дни, переносы пропущенных тренировок.
- **Еда** — дневник по дням, калькулятор КБЖУ, избранные блюда в один тап, отчёт за неделю.
- **Прогресс** — вес со средним за 7 дней и ориентирами сушки, выводы «±150 ккал»,
  пульс покоя, колено 0–10, обхваты, тесты и расчёт прыжка по замедленному видео.
- **Тело** — сон, растяжка, самомассаж, восстановление.
- **Справка** — все правила плана: сессия, прогрессия весов, колено прыгуна, тесты, календарь.

Неделя выбирается сама по дате (старт — пн 05.10.2026, после сушки — сессионный блок, по умолчанию 4 недели).
Это настраивается в окне выбора недели (шестерёнка в шапке).

## Данные

- Все записи хранятся только на телефоне.
- Сайт в Safari и приложение с экрана «Домой» хранят данные раздельно — пользуйся иконкой.
- Резервная копия: «Справка» → «Данные и резервная копия» → «Сохранить копию» (в Файлы или Telegram).
